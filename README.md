# hoopIndex

**Live page → https://bloodwill.github.io/HoopIndex/**

Nightly NBA player projections with honest uncertainty — the ranked board plus a
per-player card (style label, error bars, games range, fingerprint).

This repository holds only the generated page (`index.html`); it is re-baked and
pushed every night by the projection engine, which lives in a private repository.
Projections, not advice. Not affiliated with the NBA or any team; player names and
statistics are facts of the public record.
